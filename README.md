# Sidcup Golf Family Clone

A **responsive and interactive** clone of the Sidcup Golf Family website, built using modern web technologies with smooth animations.

## 🚀 Features

- **Fully Responsive** – Works seamlessly on all devices.
- **Smooth Animations** – Integrated using [GSAP](https://greensock.com/gsap/) and [ScrollTrigger](https://greensock.com/scrolltrigger/).
- **Optimized Performance** – Fast loading and smooth navigation.
- **Interactive UI Components** – Engaging and dynamic user experience.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript  
- **Animations:** GSAP, ScrollTrigger  
- **Other Tools:** Responsive Design, Performance Optimization  

## 🔧 Installation

1. Clone this repository:
   ```sh
   git clone https://github.com/sujit-patel/sidcup-golf-family-clone.git
   ```
2. Open index.html in your browser.
